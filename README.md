# 📖 Overview

Career Recommendation System is an intelligent web application built using **Flask** and **Machine Learning** that helps students and professionals choose the most suitable career based on their skills, education, interests, and resume quality.

The application also provides an ATS Resume Checker, personalized learning recommendations, analytics dashboard, and secure authentication.

# ⚙ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Khushi736/Career-Recommendation-System.git
```

---

## 2️⃣ Navigate to Project

```bash
cd Career-Recommendation-System
```

---

## 3️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv
```

Activate

```bash
venv\Scripts\activate
```

---

### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 5️⃣ Configure Environment Variables

Create a `.env` file.

Example:

```env
EMAIL_USER=your_email@gmail.com
EMAIL_PASSWORD=your_password
GEMINI_API_KEY=your_api_key
SECRET_KEY=your_secret_key
```

---

## 6️⃣ Run the Application

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
